# Sistema de Registro y Firma Digital de Minutas - HGZ No. 49
### Modelo Institucional de Competitividad (MC) | OOAD Sinaloa

Aplicación web optimizada para dispositivos móviles (smartphones y tablets) y computadoras para el registro ágil de asistencia, captura de acuerdos/indicadores y estampado de firma autógrafa a mano alzada en sesiones de trabajo.

🌐 **Enlace Oficial en Línea (GitHub Pages):**  
👉 **[https://gildardomaro.github.io/CC/](https://gildardomaro.github.io/CC/)**

---

## Características Principales
1. **Lienzo de Firma Táctil (Canvas):** Optimizado para trazos fluidos en pantallas táctiles de celulares o tablets con dedo o lápiz stylus.
2. **Campos Oficiales de Captura:**
   - Nombre completo y cargo/área.
   - Matrícula institucional.
   - Asuntos relevantes o acuerdos abordados.
   - Indicadores hospitalarios y porcentaje de cumplimiento.
3. **Pestaña de Asistentes Registrados:** Monitoreo en tiempo real del quórum con previsualización de firmas digitales capturadas.
4. **Exportación y Compilación:**
   - Descarga directa en JSON (`datos_minuta.json`).
   - Exportación a formato CSV / Excel.
   - Integración automática con el generador local de Minuta oficial en Word (`.docx`) y PDF.
